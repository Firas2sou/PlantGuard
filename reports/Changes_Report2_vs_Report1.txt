4. NEW SECTION 7 - WEB APPLICATION  (entirely new content)
----------------------------------------------------------
  - Architecture: FastAPI server (src/serve/app.py) + one static page
    (web/index.html). No Node.js, no bundler.
  - Endpoint table: GET / , GET /health , POST /predict
  - Pre-processing chain: short side resized to 256 px, centre crop 224x224,
    ImageNet normalisation - identical to training
  - Disease record from knowledge/diseases.json (crop, pathogen, symptoms,
    treatment, prevention)
  - Confidence gate: below 0.60, or margin under 0.15 over the runner-up,
    the answer is "not sure"
  - Verification: 298/300 test images correct through the API (99.3 %),
    matching the training test accuracy; manual checks returned apple scab
    at 92.8 % and tomato late blight at 82.8 %
  - Command to start the service

This new section pushed every later section down by one number.
